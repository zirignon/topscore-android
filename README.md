# Top Score pour Android

Application de Scrabble : meilleur coup avec % de gain, duplicate chronométré,
arbitre virtuel, entraînement et directs des tournois.

**Télécharger :** [topscore.apk](https://github.com/zirignon/topscore-android/raw/main/topscore.apk)
(toujours la dernière version : 1.1.0, construction 8, du 5 novembre 2026) · présentation sur https://tournoi.topscore.ci/app

## Installer
1. Ouvrez le fichier téléchargé.
2. Si Android le demande, autorisez l'installation depuis votre navigateur (une seule fois).
3. Installez, puis ouvrez Top Score. Les mises à jour arrivent ensuite toutes seules.

Ce dépôt ne contient que les fichiers d'installation (pas le code de l'application).
Contact : contact@topscore.ci
